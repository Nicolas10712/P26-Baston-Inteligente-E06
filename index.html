Prototipo físico

Diseñado para el camino. Construido con propósito.

Un bastón de asistencia que integra un ESP32 y un sensor ultrasónico HC-SR04 para detectar obstáculos, activar avisos locales y transmitir telemetría en tiempo real.

Aviso multisensorial

LED, buzzer y motor de vibración según la distancia del obstáculo.

Posicionamiento GPS

Módulo GPS por UART2 para incorporar ubicación a la telemetría.

Diseño 3D

Cada pieza, diseñada a medida. Gírala tú mismo.

Las carcasas del bastón se modelaron e imprimieron en 3D. Arrastra para rotar, usa la rueda o pellizca para hacer zoom, y descarga los STL para imprimirlos.

Reproducir el proyecto

Compilar en cinco pasos.

Versión de referencia: demo_P26_GT6_ERROR_BOTON_3S_GPIO22.ino

Abrir

Firmware final en Arduino IDE con placa ESP32 Dev Module.

Configurar

Copiar config.example.h como config.h y completar Wi-Fi y MQTT.

Bibliotecas

PubSubClient, ArduinoJson, TinyGPSPlus y núcleo ESP32.

Cargar

Compilar y cargar a 115200 baudios con Monitor Serie.

Integrar

Importar Node-RED y Grafana ajustando MQTT y fuentes de datos.

🔒 Nunca subir a GitHub el archivo privado config.h, contraseñas, tokens ni claves.

Firmware y evidencias

Este sistema es un prototipo académico y no constituye un dispositivo certificado de movilidad ni reemplaza otras ayudas de desplazamiento. Su desempeño depende, entre otros factores, de la geometría, reflectancia y cobertura del sensor ultrasónico. La simulación diagnóstica de ERROR_SENSOR valida la FSM y el botón físico, pero no equivale a una desconexión eléctrica detectada automáticamente.
